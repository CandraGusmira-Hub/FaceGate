# 🔐 FaceGate

FaceGate adalah aplikasi **Face Authentication System** berbasis Python yang menggunakan webcam dan teknologi facial recognition untuk melakukan autentikasi pengguna sebelum memberikan akses ke halaman dashboard.

---

## 📖 Pengenalan Aplikasi

FaceGate dibuat sebagai project pembelajaran untuk memahami penerapan **Computer Vision** dan **Web Authentication** menggunakan Python.

Aplikasi menggunakan OpenCV untuk mendeteksi dan mengenali wajah pengguna yang telah terdaftar.

### ✨ Fitur Utama

- 🔐 Face ID Authentication
- 📷 Real-time Webcam
- 🧠 Face Detection
- 👤 Face Recognition
- 📝 Face Registration
- 🧠 LBPH Face Recognizer
- 🌐 Flask Web Application
- 🔒 Protected Dashboard
- 📊 Authentication Status
- 📱 Responsive Dashboard

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Flask | Backend & web server |
| OpenCV | Computer vision |
| OpenCV-Contrib | LBPH Face Recognition |
| NumPy | Image data processing |
| HTML | Web structure |
| CSS | User interface |
| JavaScript | Webcam integration |
